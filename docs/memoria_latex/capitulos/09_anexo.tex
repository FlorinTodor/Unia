\section{Cómo probarlo}\label{sec:anexo}

\begin{lstlisting}[language=bash,basicstyle=\ttfamily\footnotesize]
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt            # requirements-voz.txt es opcional (OmniVoice, GPU)
cp .env.example .env                       # CONTRASENA_ADMIN (12+ caracteres) y, si se quiere, GROQ_API_KEY
uvicorn backend.main:app --no-proxy-headers
python -m piper.download_voices es_ES-sharvard-medium --data-dir data/voces   # voz del servidor (opcional)
pip install -r requirements-dev.txt && python -m pytest -q   # tests, sin red ni clave
\end{lstlisting}

Abrir \url{http://localhost:8000} y entrar con \cod{alex}, \cod{ana}, \cod{marta} o \cod{jose}. La contraseña de demostración es el usuario
seguido de 2026, salvo que \cod{.env} defina otra. La clave de Groq puede ir en \cod{.env} o pegarse en el panel de ajustes con el
perfil \cod{admin} (contraseña \ruta{CONTRASENA_ADMIN}): la aplicación la valida, la guarda en el servidor y la usa para el chat y la voz.
